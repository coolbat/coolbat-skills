# 使用示例与内部规格

## 一句话生成

用户：`使用 $pear-portrait-director：午后花店，玻璃门边，刚挑好一束花。`

补全P01成年女性、梨形微胖、3:4、自然手机摄影；选合场景的衣服，低持花束避免无意遮挡腰髋。直接调用可用生图工具，不先输出提示词要求确认。

## 摄影和体型

用户：`梨形微胖，冷白清透CCD，奶白针织上衣、深蓝直筒牛仔裤，窗边站姿，3:4。`

保持梨形圆润，摄影只改变色温、反射和成像；不从外部同名摄影路线导入纤细体态或其他身体默认值。不添加数字化腰臀比。

## 局部编辑

用户：`这张只改粉白渐变高双马尾公主切，白色蝴蝶结。`

当前图为edit_target，只改头发发饰及必要影子；锁定脸、体态、裙子、姿势、手部、背景、机位、画幅。缺图请重传，不创造相似人物冒充编辑。

## 特写

用户：`同样体型偏好，脸部特写，粉白双马尾，真人手机摄影。`

遵守特写，保持成年感和自然脸颊。体型仍在规格中，但梨形不可判断，不拉远镜头或因此重生。

## 多图角色

用户：`第一张只参考脸，第二张只参考体型，第三张参考光线，去海边。`

分别采用身份、可见体态和摄影光线；海边细节合理补全。图片缺失时只询问缺失输入。

## 提示词模式

用户：`只要英文提示词：成年梨形女生，公园长椅，绿色连衣裙。`

返回一条等义英文，保留默认3:4和微胖比例；不生图，不默认解析、五段或未知模型参数。

## 同人系列

用户：`用刚才那个人，改到公园。`

引用实际上一张图保持身份体态和未修改内容。只有文字时不能保证同脸，首张出图后再以它为依据继续。

## 精简内部记录

下列字段按任务选用，不要求回显或填写固定JSON：

| 字段 | 内容 |
|---|---|
| task | generate / edit / prompt / diagnose |
| explicit | 用户明确要求及本轮修改 |
| identity | 原型或参考图，默认P01 |
| body | 比例、丰满程度、轮廓、来源 |
| styling | 发型、服装、配饰 |
| scene | 地点、时间、单一定格事件 |
| pose | 支撑、手部、视线、布料受力 |
| photo | 一个摄影配方、光线与机位 |
| frame | 画幅、景别与来源 |
| references | 真实图片标识、角色、使用范围 |
| edit | 本轮修改项与保留项 |
| body_observability | 可见 / 部分遮挡 / 不可见 |
| execution | 实际工具、能力状态、已调用次数、每图上限3 |

把确定内容转成自然语言和工具支持参数，不把未知值、路线ID和内部字段名塞进生图提示词。
