# 视觉验收与纠错

逐项使用通过、偏差或不可判断；未看图则标为未复核。这是画面与用户要求的比对，不是对真人的医学分类或审美打分。

| 检查项 | 可见依据 | 不可判断条件 |
|---|---|---|
| 用户要求 | 场景、服装、发型、动作、人数、画幅 | 相关部位未入镜或输出不可查看 |
| 梨形比例 | 肩相对较窄，髋腿更丰满；与体型参考对照 | 特写、长衣遮挡、强透视、坐姿遮挡 |
| 圆润微胖 | 四肢、腰腹、脸颊体量协调，非局部异常放大 | 隐藏部位 |
| 身份保持 | 与实际身份图对照脸型及主要五官 | 无参考、图像太小或脸被挡 |
| 人体与支撑 | 手指、关节、承重、椅面接触合理 | 未入镜肢体 |
| 衣服结构 | 肩带腰带连贯，褶皱符合重力 | 遮住的衣服结构 |
| 摄影质感 | 肤质、发丝、反射、光线统一，修饰程度符合要求 | 只有提示词没有图片 |

可得尺寸时按实际宽高检查画幅，允许约1%取整误差；只有预览无元数据时说明目标比例，不声称精确验证。

## 是否重试

用户指定特写或宽衣造成体型不可判断是正常结果，不因此重生。可观察目标符合即可交付。

| 主要偏差 | 修复 |
|---|---|
| 变纤细、四肢骨感 | 去掉摄影/造型里的瘦身词，强化整体软体量，严重才重生 |
| 沙漏形或上半身过大 | 回到肩髋关系和下半身体量，保留自然腰腹，不放大局部 |
| 系统添加道具遮挡 | 用户没固定位置时调整；已固定则遵守 |
| 身份漂移 | 回到原始身份图，缩小可变区域，不用新脸继续强化 |
| 手部、肩带错误 | 局部编辑，锁定脸和身体 |
| 公主切不明显 | 只修刘海、侧发、扎点，保留真人成年面容 |
| 塑料皮肤或头发 | 调整纹理与高光，不把真实变粗糙脏乱 |
| 过度精修/电影化 | 回到环境光、自然景深与生活摄影 |

每轮一项主问题，并明确保留内容。最多两轮纠错；修好手却换了脸属于倒退，保留较好版本。写入提示词不等于已修复，必须再看图。

如果工具实际返回多候选，可以选择；不假设中间图能隐藏，宿主自动显示时用户可能看到每轮。最终明确采用哪张。

## 对外表达

普通成功直接展示图。确有局限才说明，例如“外套遮住腰髋，这张无法确认梨形比例”。无工具说“尚未生成”，无查看能力说“未经视觉复核”。达上限说明剩余偏差，不能宣称完美。用户要求诊断时才展开证据和修复策略。
