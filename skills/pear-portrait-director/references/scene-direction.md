# 场景与摄影编排

## 摄影配方只控制成像

配方是独立编写的摄影描述，不是特定模型的验证报告。每次选一个并根据明确要求调整，不修改身体或身份。

| 配方 | 光线与成像 | 场景原则 |
|---|---|---|
| natural-phone 默认 | 窗边散射光或阴天柔光，软阴影、适量皮肤纹理、轻数码噪点与柔软边缘 | 日常室内、楼梯、花店，保留背景辨识度 |
| soft-flash | 环境光建立空间，柔和前方补光提亮人物，轻颗粒，保留背景 | 明确卡片机柔闪、CCD生活感时 |
| cool-clear | 中性至略冷日间环境与玻璃反射，肤色自然、不全图蓝白，不必加闪 | 冷白清透需求，不能带入纤细体型 |
| warm-retro | 柔和暖环境、克制对比与细颗粒，保留衣服原色与肤质层次 | 法式公寓、旧街、复古日常 |
| oriental-natural | 现实庭院、木窗、竹影等少量线索，自然侧光、柔和材质 | 明确东方美学、旗袍、新中式时 |
| studio-soft | 柔光主光、简洁背景、可读衣料纹理，自然比例与适度修饰 | 明确棚拍时 |

CCD仅是视觉描述，不声称图片有真实相机或传感器元数据。未列出的夜景、强闪、电影等按摄影关系设计，不硬套最近配方，也不标记为已实测。

## 一个定格瞬间

选择一个小事件，描述当下承重、肩颈、手部接触、头部、视线、衣料变化；不是多个连续动作。

| 场景 | 可选定格 | 有效细节 |
|---|---|---|
| 咖啡馆 | 杯子已经落桌，一手在杯柄旁，目光转向窗外 | 雨滴玻璃、木椅、浅色杯子 |
| 楼梯 | 自然坐定，一手撑低一级台阶，另一手落裙面 | 石材台阶、米色墙、一幅装饰画 |
| 花店 | 花束由一手低握在身侧，另一手轻碰包装纸 | 玻璃门、少量花桶、街景反射 |
| 公园 | 散步间站定，重心稳定，转头看一侧 | 树荫、长椅、远处步道 |
| 海边 | 双脚踏实站定，风吹发尾和裙摆 | 海平线、浅色栏杆、海面反光 |
| 东方庭院 | 坐木椅，手落膝前，抬眼看竹影 | 木窗、竹影、素墙 |

一张图通常两三项环境细节即可。系列可变事件或构图，不每次加咖啡杯和书。胸前大花束会挡身体；若用户未固定持花方式且比例可见性重要，可改在身侧。

## 衣服与相机

- 保留用户服装颜色、材质、领口、肩带、层次；未指定时选合天气场景的合身服装。
- 背景不用所有细节锐利，也不应全部变成模糊色块。
- 默认平视或略高，约50mm等效自然视角；焦段是意图，不是实际拍摄参数。全身需足够距离，避免近大远小。
- 缺省景别保留腰髋和足够腿部信息，用户指定特写、宽衣、横幅或远景时优先。
- 环境可低饱和，紫色衣服、粉色头发仍需可识别；全图去色不能破坏指定配色。
- 温柔、知性、松弛、甜美只调整表情、动作和可变造型，不修改身体比例或摄影机制。
