# 模型与工具适配

## 先核对能力

核心摄影规格不绑定模型；直接生成取决于当前宿主与用户已接入工具。跨宿主可读不等于跨图像模型已验证。

从实际工具说明或当前官方文档确认文本生图、参考、编辑、看图、画幅/像素、负面字段、数量。未知项保持未知，不伪造seed、权重、参考强度、模型版本或质量枚举。具体产品用法优先当前本地说明，必要时查官方文档。

| 能力 | 处理 |
|---|---|
| 内置生成与编辑 | 融合提示词加必要参考图，只用实际暴露参数 |
| 用户已配置的其他工具 | 按当前schema转换，保持指定模型 |
| 只有文本模型 | 提供清楚标记“尚未生成”的可复制提示词 |
| 有生成但无法查看结果 | 可出图，不宣称通过视觉验收 |
| 有参考输入无局部编辑 | 按实际能力尝试参考生成，明确局部保持限制 |

## 输出策略

| 目标 | 提示策略 | 参数策略 |
|---|---|---|
| 当前自然语言生图工具 | 人物/体型、动作服装、环境摄影连贯描述 | 有画幅参数时使用；没有时写入提示并检查结果 |
| 中文工具或用户要中文版 | 等义中文描述，不堆标签 | 确认支持后单列尺寸、参考、负面字段 |
| 英文工具或用户要英文版 | 等义英文，体型与风格分离 | 不照搬其他模型语法 |
| Midjourney等用户点名平台 | 给自然语言描述，再按已核实版本附支持参数 | 不凭记忆加版本、人物参考、权重开关 |
| 用户指定本地工作流 | 按所给节点/接口和模型文档组织 | 不假设有LoRA、ControlNet或身份节点 |

以上是输出策略，不代表平台已接通或完成视觉测试。几段即可，不规定五段或字符下限。不默认同时给中英、多模型长版。

无独立负面字段时，把最重要限制写入主提示；支持时再单列。大量负面词不能替代正向比例描述。

## 当前内置image_gen约定

实际工具定义优先。本环境接口接受prompt；编辑可用referenced_image_paths或num_last_images_to_include，两者互斥。新图不传历史引用。未暴露的size、model、quality、seed、negative_prompt不是合法参数。

code-mode调用按宿主等待策略执行，以generatedImage(result)展示。编辑前查看本地图；遵守宿主图片Skill的保存显示要求。不为普通内置生图切外部API或要求用户粘贴密钥。

## 失败与预算

每张成片最多首次生成加两次有目的纠错。身份、手部、衣服小错优先编辑；整体比例或结构严重错误才重生。不因一次审美不满意自动批量候选。

费用、授权、速率或内容边界导致失败时遵守宿主规则，说明状态，不更换服务规避限制。瞬时错误的重试也计入预算。用户明确要更多版本属于新的数量范围。

记录实际返回工具名称、图像标识和可得尺寸。没有精确模型名则写“当前内置图像工具”；只在看过图后记录视觉结论。提示词写3:4不能代替实际比例验证。
