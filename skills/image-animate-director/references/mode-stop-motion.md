# Stop-motion mode

Set `mode` to `stop-motion`. Prioritize deliberate pose stepping, stable scene/camera/light, plausible contact and a tactile performance. Preserve the supplied material; stop-motion does not require converting everything to clay.

Use 8 action ticks/second and 24 fps preview as a starting point; specify holds for anticipation and reaction pauses. Choose loop only when requested or clearly suited to the action. Use the shared frame ledger and review commands. Watch final playback for accidental flicker versus intentional handmade texture variation.

Default delivery is MP4 plus GIF preview and editable frame records. For transparent cutouts, request actual alpha from the image tool and use PNG/WebP/atlas delivery as appropriate. The standard GIF renderer composites onto canvas.background; it is not a transparent GIF exporter.
